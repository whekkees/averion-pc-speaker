Averion PC Speaker

Небольшой драйвер PC Speaker на Rust для x86.

Драйвер использует:

PIT Channel 2
I/O-порты 0x42, 0x43, 0x61
inline assembly in / out

Поддерживает:

настройку частоты PC Speaker;
включение звука;
выключение звука.

Проект создан в процессе разработки Averion OS и предназначен для изучения низкоуровневой работы.

Драйвер рассчитан на kernel / bare-metal окружение и не предназначен для обычного запуска из userspace.
